# Character Choice — V1 corrigée

Jeu statique de duel entre personnages.

## Installation GitHub Pages
Les fichiers `index.html`, `style.css`, `app.js` et `.nojekyll` doivent être à la racine du dépôt.

Dans GitHub Pages :
- Source : Deploy from a branch
- Branch : main
- Folder : / (root)

GitHub Pages utilise `index.html` comme fichier d'entrée.

## Fonctionnalités
- Champion actuel + série de victoires
- Nouveau challenger à chaque combat
- Aucun personnage répété dans une même partie
- Historique local
- Export CSV
- Sauvegarde automatique via localStorage
- Interface mobile/ordinateur
