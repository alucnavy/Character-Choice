# Tournoi des personnages — V1
Mettre `index.html`, `style.css` et `app.js` dans un dépôt GitHub puis activer GitHub Pages depuis Settings > Pages.
Le site démarre avec deux personnages tirés au hasard, conserve le gagnant, évite les personnages déjà utilisés pendant la partie, sauvegarde localement et exporte l'historique en CSV.
